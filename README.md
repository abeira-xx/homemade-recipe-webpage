# Homemade-recipe-webpage

## 1. Project Description

Homemade Recipes is a simple webpage created using HTML and CSS. The purpose of this project is to provide an easy method of recipes. I have mentioned few, which are mostly liked my everyone.
This project helped me practise my skills and understand how HTML stuctures a web by giving the content and CSS improve its overall apperance.
The webpage includes a navigation menu, home-section, recipe section and the links of recipes, images of food and at the end providing the contact details.

## 2. Features

- **Navigation Menu:** Includes Home, Recipes, and Contact links help the visitors to go on the section which they prefer rather than scrolling, which might not be accesible for some users.
- **Recipe Sections:** Presents different food recipes, including pancakes, cookies, and pizza, pasta. Almost liked by everyone.
- **Food Images:** Uses images to make the recipe sections more attractive.
- **CSS Styling:** Applies styling to improve the layout, styling, typography, spacing, and overall appearance of the webpage.
- **Recipes button:** Provides an quick access of the recipes which the user wants to know, this is an easy and time-saving way.

## 3. Technologies I Used

- **HTML:** Used to structure the webpage by organize its content, and add headings, subheading, paragraphs, ingredients, links, and images.
- **CSS:** Used to style the webpage by adding colors, fonts, typography, margins, padding, layout, box-shadows, transform properties to create an clean and user-friendly design.
- **GitHub:** Used it to show the code and manage the project files.
- **GitHub Pages:** Used to deploy the webpage and make it accessible online.

## Project Files 

- **index.html:** Contains the structure and main content of the webpage.
- **styles.css:** Contains the CSS rules used to style the webpage.
- **images of food/:** Stores the images displayed on the webpage.
- **README.md:** Provides information about the project, its features, and the technologies used.

## 5. What I Learned and What Challenges I Faced

While developing the page, I practiced stucturing the webpage content with HTML and styling them with CSS. Oraganizing the project files, Adding the images, Adding links, Using navigation links to connect with differenty sections.
At first, I found box-shadow and transform properties interesting but difficult to understand. After practicing them and putting efforts , I learned how to use translateX, translateY, transition, scale, and skew. It took time, but practising helped me understand these properties and use them to make my projects more attractive and visually appealing.
Another Challenge i had gone through is uploading images in github. At first, It was seriously frutrated but we learn from our mistakes, after countless tries i got to know the correct method of uploading the images and their apperaance in github pages.
